# Sitio de servicios de dron

Este proyecto contiene una página estática en español para ofrecer servicios de video y fotografía aérea con dron en Colombia.

## Despliegue
1. Copia los archivos del repositorio a un hosting estático (GitHub Pages, Netlify, Vercel, etc.).
2. Asegúrate de mantener la estructura de carpetas `/assets`.
3. No requiere procesos de build; el sitio está listo para usar.

## Personalización
- **Marca y logo:** cambia el texto `AeroVista` en `index.html`.
- **Imágenes y videos:** reemplaza las URLs de Unsplash y YouTube por tus propios recursos.
- **WhatsApp y contacto:** actualiza el número en `index.html` y la URL de Formspree.
- **SEO:** modifica etiquetas `<title>`, `meta description` y los datos estructurados JSON-LD.

## Créditos
- Framework de estilos: [Tailwind CSS](https://tailwindcss.com/)
- Imágenes de ejemplo: [Unsplash](https://unsplash.com/)
